# myportfolio

Personal portfolio site. Static HTML, no build step — same setup as Pulse.


## Deploy

Same as Pulse: upload these files to the `myportfolio` repo (keeping `projects/pulse.html` inside its `projects` folder), then Settings → Pages → Deploy from branch → main → / (root).

## Add another project later

Duplicate `projects/pulse.html`, rewrite it, and add a new `.card` block to `index.html` linking to it.
