# myportfolio

My Portfolio Website: https://sahithiyakkali.github.io/myportfolio/index.html.

## What's here
- `index.html` — home: photo, bio, build log (projects), work experience, education, hobbies
- `projects/pulse.html` — Pulse case study
- `projects/supplyshield.html` — SupplyShield case study, with real screenshots from the original deck
- `images/` — my photos and the SupplyShield dashboard screenshots

## Deploy
Upload everything (keeping `projects/` and `images/` as folders, not flattened) to the repo root, then Settings → Pages → Deploy from branch → main → /(root).

## Add a project
Duplicate `projects/pulse.html`, rewrite it, and add a new `.entry` block to `index.html`'s build log.

## Add a job or hobby
Copy a `.job` block or `.hob` span in `index.html` and edit the text.
